# QQ 集成（qq_auto_reply）

让 N.E.K.O 角色在 QQ 私聊和群聊中交流，支持文字、语音、图片、表情包，以及按权限调用其他插件工具。具体能力取决于接入通道和本体配置。

## 版本选择

| 版本 | 分支 | 适用场景 |
| --- | --- | --- |
| v0.16.0 稳定版 | `main` | QQ 官方开放平台；首页提供扫码绑定和开放平台配置 |
| **v0.16.1-beta.1 测试版** | `beta-onebot-ui` | 需要 OneBot（SnowLuma 等）控制台、登录或部署界面 |

稳定版隐藏 OneBot 界面，**不删除后端能力，也不改动已有连接配置**，已接入的用户可以继续运行。
本分支仅提供 SnowLuma 的部署和启动支持，保留通用 OneBot 管理界面，并同步 main 的通用修复。NapCat 的界面、部署和启动支持已移除；旧配置会切换到 SnowLuma 并关闭 OneBot 开机自动启动，原安装目录与数据保留。请重新配置 SnowLuma，或自行管理外部 OneBot 服务。测试版 Release 标记为 Pre-release，不替代稳定版。

## 快速开始

1. 在 N.E.K.O 中安装并启用本插件，打开 **Hello QQ** 面板。
2. **OneBot**：从「一键部署」配置后端，或进入 OneBot 控制台连接已有服务。**开放平台**：进入接入页扫码绑定，或填写 **AppID / ClientSecret** 并保存。
3. OneBot 按后端提示完成登录；开放平台需确认应用可用范围，沙箱模式需配置测试群和测试者。
4. 点击「启动」，私聊机器人或在群里 **@机器人** 测试回复；没有响应时先查看面板日志。
5. 按需配置用户权限、记忆开关和插件工具授权，不要把管理员权限开放给所有人。

测试版同时提供 OneBot 和开放平台入口；进入对应控制台会选择该通道，管理已有 OneBot 连接请进入 OneBot 控制台。

## 常用功能与边界

- **群聊回复**：接话判定、注意力管理和消息缓冲；并非每条消息都会回复，触发规则因通道而异。
- **语音与图片**：语音复用本体角色、音色和 TTS 配置，不另存一套密钥；表情包收集默认须逐群授权，关闭收集不会删除旧库存。
- **记忆隔离**：授权后，群聊可只读当前真实发言人的私聊记忆；私聊不检索群聊记忆，群聊结算不写入私聊域。跨群上下文开关只共享会话元数据，不等于共享聊天记录。
- **工具与主动搭话**：其他插件工具须单独授权；管理员私聊的定时问候默认关闭，仍受额度、静音和近期聊天限制。
- **视频概况**：搭配 `video_reader` 和可用的本体视觉配置，支持公开视频链接的抽样画面分析；不分析声音，也不代表看完了整段视频。

配置细节、记忆授权条件、语音兼容路径、定时问候及 OneBot 说明见[使用与配置](docs/usage.md)。

## v0.16.0 升级须知

**升级后重新加载 QQ 插件生效，无需修改本体。** 本分支已同步稳定版 v0.16.0 的两项简化：

- **只保留一套账号关联**：在「配置 → 用户 → 账号关联」将新 ID 关联到已有名册账号，或使用管理员签发的一次性认领码。管理员也须明确关联，不再自动匹配；不迁移或合并历史记忆。旧 `identity_bind` / `identity_unbind` / `claims` 入口移除，已有宿主绑定不删除。
- **退役提示词覆盖**：删除 `prompt_save`、`prompt_reset`、`group_prompt_save`、`group_prompt_delete`；重新加载时清除所有语言和群的 `prompt_overrides` / `group_prompts`。运行时不再读取旧覆盖，即使清理写盘失败也不会生效。角色个性由本体角色设定提供，不修改权限、记忆或聊天记录。

完整迁移边界和失败处理见[使用与配置](docs/usage.md)，历史版本变化见[更新记录](CHANGELOG.md)。

## 开发

宿主检出在同级 `../N.E.K.O` 时，从插件目录运行测试：

```powershell
& ../N.E.K.O/.venv/Scripts/python -m pytest tests -q -o asyncio_mode=auto
```

分支同步、发布及 lint 规则见 [AGENTS.md](AGENTS.md)；实验性只读陪伴背景见[专项说明](docs/companion-context.md)。
